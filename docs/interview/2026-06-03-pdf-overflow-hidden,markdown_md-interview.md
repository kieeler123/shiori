# 오늘의 개발 기록

## 日本語

### 今日何をしたか？

- PDF Viewer の表示切れ問題を調査した。

### 何を発見したか？

- `overflow-hidden` とページ幅計算の問題が原因である可能性が高かった。

### 何を学んだか？

- Markdown の標準記法を使うことで PDF 変換や表示の問題を減らせることを学んだ。

### 次に何をするか？

- 既存の文書を段階的に Markdown 標準形式へ移行する予定である。

---

## English

### What did I do today?

- I investigated a clipping issue in the PDF Viewer.

### What did I discover?

- The issue was likely caused by `overflow-hidden` and incorrect page width calculations.

### What did I learn?

- Using standard Markdown syntax reduces PDF conversion and rendering issues.

### What will I do next?

- I plan to gradually migrate existing documents to standard Markdown formatting.

---

## 한국어

### 오늘 무엇을 했는가?

- PDF Viewer가 일부 잘리는 문제를 조사했다.

### 무엇을 발견했는가?

- `overflow-hidden`과 잘못된 페이지 너비 계산이 원인일 가능성이 높았다.

### 무엇을 배웠는가?

- Markdown 표준 문법을 사용해야 PDF 변환과 렌더링 문제를 줄일 수 있다는 점을 배웠다.

### 다음에 할 일은?

- 기존 문서들을 점진적으로 Markdown 표준 형식으로 전환할 예정이다.
