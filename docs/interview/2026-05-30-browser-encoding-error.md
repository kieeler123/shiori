# Interview Style Record

## 日本語

Q. 今日解決した技術的な課題は何ですか？

A. Supabase Storage の Public URL 経由で表示した Markdown ファイルが文字化けする問題を解決しました。Vercel のログを分析し、Serverless Function を実装して UTF-8 として正しく処理できるように改善しました。

---

## English

Q. What technical issue did you solve today?

A. I resolved an encoding issue where Markdown files displayed through Supabase Storage Public URLs appeared corrupted. I analyzed Vercel logs, implemented a Serverless Function, and ensured that files were decoded and rendered correctly using UTF-8.

---

## 한국어

Q. 오늘 해결한 기술적인 문제는 무엇인가요?

A. Supabase Storage Public URL을 통해 표시되는 Markdown 파일의 한글 깨짐 문제를 해결했습니다. Vercel 로그를 분석하여 원인을 추적했고, Serverless Function을 구현하여 UTF-8로 정상 디코딩 및 렌더링되도록 개선했습니다.
