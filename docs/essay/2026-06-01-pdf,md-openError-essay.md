# 日本語

- 今日はShioriの添付ファイル機能の問題を解決するために多くの時間を使った。
- 最初はPDFファイルが壊れていると思ったが、調査を進めるうちにPDF自体には問題がなく、表示方法に問題があることが分かった。

- 詳細ページと編集ページで異なる処理が使われており、その違いが原因でMarkdownとPDFの挙動が変わっていた。
- ログを確認しながら原因を一つずつ特定し、最終的には両方のファイルを正常に開ける状態にできた。

- 作業には時間がかかったが、問題解決の流れを最後まで追えたことは良い経験になった。

# English

- Today I spent a significant amount of time fixing the attachment system in Shiori. At first I thought the PDF files themselves were corrupted, but - after investigating I realized the issue was related to how the files were being displayed.

- The detail page and the edit page were using different approaches to open files, which caused Markdown and PDF files to behave differently. By - checking logs and testing each step, I was able to identify the cause and eventually make both file types work correctly.

- Although it took a long time, it was a valuable experience because I followed the debugging process from start to finish.

# 한국어

- 오늘은 Shiori의 첨부파일 기능 문제를 해결하는 데 많은 시간을 사용했다.

- 처음에는 PDF 파일 자체가 손상된 줄 알았지만, 조사해보니 실제 문제는 파일 자체가 아니라 파일을 표시하는 방식에 있었다.

- 상세페이지와 수정페이지가 서로 다른 방식으로 첨부파일을 열고 있었고, 그 차이 때문에 Markdown과 PDF가 서로 다르게 동작하고 있었다.

- 로그를 확인하고 원인을 하나씩 추적하면서 문제를 좁혀 나갔고, 최종적으로는 두 형식 모두 정상적으로 열 수 있도록 수정했다.

- 시간은 오래 걸렸지만 문제를 끝까지 추적해서 해결했다는 점에서 의미 있는 작업이었다.
